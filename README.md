### [Library][library]

An AI Product & Workflow Library.

Most people use only a small fraction of the tools they already pay for.

Library helps users unlock the real value behind subscriptions such as:

- Claude
- ChatGPT
- Cursor
- Warp
- Gemini
- Kimi
- Agent Platforms

through practical workflows, field guides, and deep product understanding.

### [SKILLS][skills]

An open framework for building personal design languages.

Not a design system.

A system for helping individuals define:

- Visual Language
- Writing Language
- Product Language
- Knowledge Language
- Personal Brand Language

so their work remains consistent across websites, documents, presentations, media, and products.
